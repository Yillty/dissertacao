# IMPACTOS LOCAIS DA INFRAESTRUTURA CICLOVIÁRIA: UMA ANÁLISE PARA A CIDADE DE NITERÓI

Este é o repositório no qual todos os processos de manejo de microdados e inferência causal utilizados na minha dissertação foram realizados. As pastas de bibliografia e dados brutos foram excluídos por conterem dados sensíveis que não podem ser disponibilizados ao público.

## Organização do Repositório

A rotina foi dividida em três arquivos:
1. Dissertação: Tratamento de Dados - No qual a maior parcela do tratamento, compatibilização e confecção de gráficos foram realizados;
2. Densidade (2000-2022) - Caderno separado para a compatibilização dos dados dos sensos demográficos foi feita, visando manter um fluxo lógico dentro do caderno principal;
3. Routine_R - Tendo em vista a escassa documentação da metodologia escolhida para a dissertação, optei por utilizar o R para as regressões finais do trabalho, é neste arquivo em que o modelo DiD com múltiplos períodos de tempo está armazenado.
